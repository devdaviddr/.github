# .github

Default issue and pull request templates for every public `devdaviddr` repo that
doesn't define its own in `.github/`.

- **Feature / task**, **Bug** and **Spike** issue templates
- A pull request template that starts with `Closes #`

Issues follow one format:

- **Title:** `type(scope): imperative summary`. Types: `feat` `fix` `chore` `docs` `refactor` `test` `spike`.
- **Body:** Why · Done when · Notes.
- **Labels:** `bug` `enhancement` `docs` `chore` `spike`, plus `track` to auto-add to the board.

Tracked on the private project board **devdaviddr — Public repos**
(github.com/users/devdaviddr/projects/11), which holds Status, Priority, Size and Target date.
